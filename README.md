# 溯证

溯证是面向本机使用的企业资料与证据分析工具，可将文档和数据表中的信息与其原始来源关联，支持资料管理、检索、统计和分析报告。

本分支包含资料分析工作台。仓库默认的 `main` 分支目前是基础资料库，功能范围与本分支不同。

## 功能介绍

### 企业资料管理

导入 TXT、Markdown、DOCX 和文本 PDF，保存文件原件、SHA-256 和可定位的文字片段。资料可标注企业、类别、部门、期间、范围、来源、标签和版本，支持关联旧版本及归档。原件可下载核对。

图片和扫描 PDF 可通过 Windows OCR 识别；用户对照原件修正文字并确认后，结果才加入资料库。扫描 PDF 最多处理 50 页。

### 资料检索与来源核对

使用关键词搜索全部资料或指定资料，查看命中片段及来源位置，并跳转原文。配置本地向量服务后，可构建语义索引并进行语义检索。分析时，系统还会对部分可识别的数值和规则作保守比较，列出需要人工核对的差异。

### 数据表统计

导入 CSV、XLSX，选择表头行或工作表，查看列质量和原始行。按列筛选与分组，计算合计、平均值、最大值、最小值或记录数；计算结果保留筛选条件、来源位置及缺失或无效值信息，可重新查看并导出 Excel。

### 资料分析与建议

输入企业问题，可选择资料联合、运营、企业或数据分析视角，自定义检索任务和资料范围，并关联已保存的统计结果。提供三种方式：

- **原文摘录**：展示检索到的来源内容与待核对线索。
- **本地模型辅助**：使用本地模型综合证据，返回带引用的结论。
- **Codex 智能分析**：结合所选资料、适用的经营指标和统计结果生成分析与行动建议；当表格字段符合规则时，可自动生成部分经营、客户、渠道和回款统计。

模型引用会检查是否与本次提供的证据逐字一致。差异和结论需要结合资料版本、期间及统计口径进行人工判断。

### 分析档案与报告

保存问题、证据、结论、差异线索和核对记录，支持查看历史档案、记录事项状态。可导出 Word 分析报告，以及包含结论、建议和来源的 Excel 清单；符合条件的统计结果可在 Word 报告中展示为图表。

### 订单与退款核算

导入 CSV、XLSX 订单及退款明细，按订单归属或退款发生日期选择退款口径，并按来源、商品及日期筛选。生成的核算快照可查看、复算并导出带来源的 Excel。

### 备份与迁移

下载包含数据库快照和原始资料的备份。提供旧版工作空间迁移工具，将支持的资料与部分历史记录迁入新的空目录；迁移后应根据报告核对跳过的记录。

## 环境与启动

需要 Python 3.12 或更高版本。文本 PDF 解析依赖 `requirements.txt`。

```bash
python -m pip install -r requirements.txt
python main.py --open
```

Windows 也可运行 `start.cmd`。默认访问地址为 `http://127.0.0.1:8765`。可通过 `--port` 和 `--data-dir` 指定端口与数据目录；按 `Ctrl+C` 停止服务。

```bash
python main.py --port 8766 --data-dir ./data-local --open
```

服务只监听本机回环地址，适用于单机使用。默认运行数据位于 `data/`，应自行备份，勿提交到公开仓库。

## 模型与语义检索

资料摘录和表格统计无需模型。本地模型辅助使用 `127.0.0.1:18770` 的兼容服务，本地语义检索使用 `127.0.0.1:18771` 的向量服务；需要自行提供对应模型和运行环境，仓库不包含模型权重。`requirements-model.txt` 和 `tools/serve_local_models.py` 可用于本地模型部署。

选择 Codex 智能分析时，需先安装并登录 Codex，在页面确认后，问题、所选资料的检索证据、数据表字段信息和统计结果会交由 Codex 处理；请根据资料权限选择使用方式。模型输出的引用会核验原文，但结论与建议仍需人工审阅。

## 演示与测试

可在新的空目录创建虚构演示资料：

```bash
python tools/create_demo.py ./demo-data
python main.py --data-dir ./demo-data --open
```

演示目录必须为空；示例数据仅用于功能体验，不代表真实企业数据。

运行自动测试：

```bash
python -m unittest discover -s tests -v
```

`tools/import_previous_workspace.py` 可将受支持的旧版工作空间迁入新的空目录，并保留旧数据库快照。迁移后应检查跳过的资料、统计记录及分析档案，再使用新工作空间。
